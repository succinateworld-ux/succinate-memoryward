# Kiroween 2026 submission checklist

Verified official sources on November 21, 2026:
- https://kiroween.devpost.com/
- https://kiroween.devpost.com/rules

Deadline: December 4, 2026 at 2 PM PST = 11 PM WAT (Africa/Lagos). Aim to submit December 2, leaving time for corrections.

All boxes are pending. Planning is not registration or submission.

- [ ] User confirms eligibility and accepts official terms in Devpost.
- [ ] Register for the event.
- [ ] Confirm category against current official wording.
- [ ] Build a new functioning app during the permitted period, with meaningful actual Kiro use.
- [ ] Preserve evidence and write an accurate Kiro-use explanation.
- [ ] Commit the actual root .kiro directory; do not ignore it.
- [ ] Publish complete source and assets on public GitHub with detectable open-source license and reproducible setup instructions.
- [ ] Disclose any reused libraries, templates and pre-existing assets.
- [ ] Deploy a reliable working app with unrestricted judge access through judging.
- [ ] Record actual app use and publish a public YouTube demo shorter than three minutes.
- [ ] Fill in English Devpost description, repository, app, video and required Kiro-use fields.
- [ ] Check all links signed out; verify final submission status and retain the receipt.
- [ ] If desired, apply for event Kiro credits before December 1 at noon PST (9 PM WAT), allowing processing time. Verify current resource-form terms first.
- [ ] Only claim bonus eligibility supported by actual work and personal eligibility evidence.

Judging weights: impact, technical implementation, design, innovation and presentation, each 20%. A polished UI does not replace a working product or required Kiro usage. Prize outcomes are not guaranteed.
